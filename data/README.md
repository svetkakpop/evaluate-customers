# data/

Положите сюда `train.parquet`. Он не входит в
репозиторий.

Четыре `.npz` лежат в репозитории через Git LFS - чтобы не пересобирать их ради
переобучения сети: стадиям 09 и 10 нужны только они и `train.parquet`, признаки
им не нужны.

```
run_pack.npz          0.4 МБ   календарь и порядок пользователей     в git (LFS)
deploy_pack.npz        15 МБ   пакет обучения для границы 408        в git (LFS)
validation_pack.npz    43 МБ   пакет обучения для оценки на 378      в git (LFS)
oof_panel.npz          38 МБ   панель остатков, purge 42             в git (LFS)
```

Признаки конвейер создаёт сам, они в git не попадают - 7.5 ГБ:

```
features/X.npy X2.npy X4.npy X6.npy   матрицы признаков
features/y.npy meta*.json             таргеты и описания колонок
```

Выгрузить содержимое LFS после клонирования:

```bash
git lfs install && git lfs pull
```

Без этого вместо `.npz` приедут текстовые указатели; стадии скажут об этом прямо,
а не упадут с непонятной ошибкой.
